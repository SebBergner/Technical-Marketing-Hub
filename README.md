# Technical Marketing Hub

A self-contained, static HTML mockup of a unified content repository for PTC Technical Demo Development — replacing the fragmented SharePoint Demo Portal + Consensus + Seismic setup with one searchable Hub for Videos, LDKs, VDKs, and Virtual Machines.

## Contents

- `index.html` — the full mockup (search, Latest Uploads / Most Viewed, Browse by Product, asset cards, a video preview page with an AI-generated "Value Roadmap index", Share-to-Consensus-DemoBoard and Add-to-PTC-Velocity modals). No build step, no dependencies — open the file directly in a browser.

## Status

Early-stage mockup for internal review. Next step: host on Azure (Static Web Apps).
